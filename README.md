# PROJECT

## Name

**SpiralSense**

## Tagline

**Make the Invisible Pattern Visible.**

## Mission

SpiralSense is a privacy-first browser extension that detects **when intentional browsing slowly turns into unconscious doomscrolling**.

Unlike screen-time apps, SpiralSense does **NOT** measure time.

It measures **behavior**.

Everything happens locally.

No AI.

No Machine Learning.

No content analysis.

No cloud processing.

No user tracking.

The system detects scrolling spirals using only:

- Scroll Velocity

- Dwell Time (pause between scrolls)

This is a deterministic rule-based system, making every decision completely explainable. fileciteturn0file0L43-L58
